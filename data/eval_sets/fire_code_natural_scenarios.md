## 二、上下文追问问题

### C001 疏散楼梯宽度追问

1. 高层公共建筑疏散楼梯的最小净宽是多少？
2. 那如果是医疗建筑呢？
3. 这两个数值为什么不一样？
4. 你把对应的表号、条文号和 PDF 页码列出来。

考察点：代词指代、同表对比、证据回溯。

### C002 车库疏散距离追问

1. 汽车库室内任一点到最近人员安全出口的疏散距离是多少？
2. 如果设置了自动灭火系统，会不会放宽？
3. 地下汽车库也是这个要求吗？
4. 这个结论来自哪一条原文？

考察点：上下文保持、条件变化、专项规范定位。

### C003 中庭防火分隔追问

1. 商业建筑里有中庭，上下层连通时防火分区面积怎么计算？
2. 如果中庭四周要做防火分隔，可以用防火卷帘吗？
3. 用防火卷帘的话，耐火极限和联动关闭有什么要求？
4. 这里有没有需要提示人工复核的地方？

考察点：同条文多段信息、措施追问、风险提示。

### C004 通用规范与旧版规范追问

1. 按建筑防火通用规范，公共建筑每个防火分区的安全出口数量怎么确定？
2. 旧版建筑设计防火规范里有没有类似条文？
3. 如果两份规范都检索到了，回答时应该优先引用哪份？
4. 把新旧规范的依据都列出来，但最终结论要说明优先级。

考察点：跨规范冲突、现行规范优先、引用并列展示。

### C005 消防电梯前室追问

1. 消防电梯前室面积有什么要求？
2. 那它的门防火性能呢？
3. 这两个问题是不是同一个条文？
4. 请分别给我对应标准、条文和页码。

考察点：同对象不同属性、避免把面积条文和门条文混答。

## 三、场景化合规判断问题

第三类用于测试系统是否能把自然语言里的项目条件转成规范检索需求，并在证据不足时提示复核。

| ID | 问题 | 主要考察点 | 期望行为 |
|---|---|---|---|
| J001 | 我有一个地下汽车库，设置了自动灭火系统，室内最远点到人员安全出口大概 58 米，这个距离能不能接受？ | 数值判断 + 条件识别 | 引用 GB 50067-2014 / 6.0.6，并说明自动灭火条件下 60m |
| J002 | 一个普通高层公共建筑，疏散楼梯净宽做成 1.15 米，可以吗？ | 合规判断 + 表格比较 | 引用 GB 50016-2014 / 5.5.18，提示普通高层公共建筑通常 1.20m |
| J003 | 如果是高层医疗建筑，疏散楼梯净宽 1.25 米够不够？ | 特殊建筑类型判断 | 引用 GB 50016-2014 / 5.5.18，提示高层医疗建筑 1.30m |
| J004 | 商业综合体中庭四周准备用防火卷帘，耐火极限 2 小时，是否足够？ | 措施合规判断 | 引用 GB 50016-2014 / 5.3.2，提示防火卷帘耐火极限不应低于 3.00h |
| J005 | 建筑里疏散出口门净宽 0.78 米，但人流很少，这样可以吗？ | 最低值判断 | 引用 GB 55037-2022 / 7.1.4，提示不应小于 0.80m |
| J006 | 我只知道这是一个公共建筑，但不知道层数、面积和人数，能不能判断是否只需要一个安全出口？ | 信息不足拒答 | 应提示缺少层数、面积、人数、建筑类型等条件，不直接下结论 |
| J007 | 南京地方消防审查对商业中庭防火卷帘有没有额外要求？ | 知识库边界 | 应说明当前知识库不含南京地方审查口径，只能引用已收录国家规范 |
| J008 | GB 50016-2014 原版和 2018 年版所有修订差异有哪些？ | 超出知识库结构能力 | 应低置信或提示需要专门修订对照材料 |
| J009 | 车库里有 90 辆车，是地下汽车库，想只设一个汽车疏散出口，是否可以？ | 条件组合判断 | 引用 GB 50067-2014 / 6.0.10，检查地下/半地下、双车道、停车数量和面积 |
| J010 | 一个商业建筑设置自动扶梯连通上下层，防火分区面积应该按单层算还是叠加算？ | 场景规则判断 | 引用 GB 50016-2014 / 5.3.2，说明上下连通开口需叠加计算 |
| J011 | 消防电梯前室门用了普通木门，但前室面积满足要求，这样可以吗？ | 多属性区分 | 应分别引用面积条文和门防火性能条文，提示门防火性能不应混同于面积要求 |
| J012 | 用户只问“这个建筑合规吗”，没有上传 IFC，也没有描述建筑类型和尺寸。 | 极端边界 | 应拒绝直接判断，并要求补充建筑类型、高度、层数、面积、用途和关键构件信息 |
